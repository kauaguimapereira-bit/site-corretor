# site-corretor
Site institucional e portfólio profissional para o corretor Fernando Silveira.

# 🏢 Site Oficial - Fernando Silveira | Corretor de Imóveis

Landing page moderna, responsiva e focada no mercado imobiliário de alto padrão em Joinville e região.

---

## 🎨 Sobre o Projeto

Este site foi desenvolvido com foco em alta conversão e experiência de usuário (*UI/UX Premium*), apresentando imóveis de luxo, depoimentos de clientes e contato direto via WhatsApp.

### ✨ Principais Funcionalidades
- **Hero Section:** Apresentação profissional com CTA direto para o WhatsApp.
- **Vitrine de Empreendimentos:** Destaques interativos dos principais projetos (*URBAN 295, LeBlanc, Atiradores ONE, etc.*).
- **Grid de Imóveis:** Exibição clara de metragens, suítes, vagas e valores.
- **Prova Social:** Seção de depoimentos e avaliações de clientes/investidores.
- **Design Moderno:** Tema dark mode com efeitos *Glassmorphism* e detalhes sofisticados.
- **100% Responsivo:** Otimizado para navegação em dispositivos móveis e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica da página.
- **Tailwind CSS:** Estilização moderna, responsiva e utilitária.
- **JavaScript:** Interatividade da página.
